What we usually find

Illustrative examples of issue types common in AI-generated code, not client data.

CRITICAL

Row-level security off

Any signed-in user can read or edit every other user's rows by calling the database API directly.

CRITICAL

Admin key in the browser

A service-role or secret API key shipped in the front-end bundle, giving full database or billing access.

HIGH

Missing ownership checks

/api/invoices/123 returns anyone's invoice: the route checks login, not ownership.

HIGH

Unsigned payment webhooks

The Stripe webhook trusts any request, so a forged call can unlock a paid plan.

HIGH

Prompt injection in AI features

User text can make your AI feature reveal its system prompt, other users' data, or call tools it shouldn't.

MEDIUM

Public storage buckets

Uploaded files, including IDs and invoices, are reachable by guessable URL.

FAQ

Why is a security review called Neural Breach?

Because finding the breach is the job. We think like an attacker on paper, inside your code, so nobody gets to do it for real. We are strictly defensive: we only review apps whose owners hire us.

Is this a penetration test?

No. It is a code and configuration review from the inside. We do not attack your running app. If you need a formal pentest for a customer or auditor, we'll tell you.

Does it work if my app wasn't built with AI?

Yes. The method is the same; AI-built apps are simply the ones that ship with the least review.

What stacks do you cover?

Next.js, React, Node, Python, Supabase, Firebase, Postgres, Stripe, Vercel, and AI SDKs (OpenAI, Anthropic and others). Ask if yours isn't listed.

How do you handle my code?

Read-only access, reviewed on isolated machines, never used to train AI models, and deleted when the engagement ends. NDA available.

Do you use AI in the review?

Yes, as a first pass alongside standard scanners. A senior human engineer verifies every finding before it reaches your report, so you get no false-alarm dumps.

What if you find nothing serious?

Then you get a written report saying so, with what we checked. That's useful for investors and customers too.
