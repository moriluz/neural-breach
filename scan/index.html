The ownership check

nb-probe refuses to scan a host that hasn't opted in. This is how you opt in.

  • Serve the token at /.well-known/neural-breach on your app's origin, the same URL you sent us. Not on the Supabase project URL.
  • It must return HTTP 200 from that exact path, with no redirect and no login in front of it.
  • The body is the token as plain text, with an optional trailing newline. JSON {"token":"..."} also works.
  • On Next.js or Vite, save it as public/.well-known/neural-breach with no file extension, then deploy.
  • Anyone who requests that URL can read the token. It's an opt-in, not a password. Remove it after the scan.
curl -i https://your-app/.well-known/neural-breach
# expect: HTTP/2 200 and the token on its own line

What the scan does, and what you get back

What runs

Eight checks: logged-out read, cross-user read, cross-user write, self-promotion of role, is_admin, plan or credits, closed-signup bypass (if you said signup should be closed), secrets and source maps in same-origin scripts, unsigned webhook, and an LLM route that answers with no session.

What it touches

It inserts one row per test user, may patch a field on a row it created, posts one unsigned test event evt_nb_probe_canary to your webhook route, and sends one "nb-probe ping" to your chat route. Probe rows are deleted before it exits. That's why staging is better.

The report

Each failed check with its severity, what it means, a curl command that reproduces it, and the fix. Then the checks that passed or were skipped, and why. Plain text by email.

This is an automated scan of cross-user data access and a few related misconfigurations, not a code review or a penetration test. A pass means the probe did not observe the failure, not that the app is safe. For a senior engineer reading your code, see Vibe ($199) and up. The scanner is open source: nb-probe on GitHub.
